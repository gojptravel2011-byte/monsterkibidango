# モンスターともだち（仮）

子ども向け2D探索RPG のMVPです。

## 動かし方

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

スマートフォンの場合はPCと同じネットワークで `http://<PCのIP>:5173` にアクセスしてください。

## 操作方法

| 操作 | 方法 |
|------|------|
| 移動 | 画面左下の仮想十字キー / キーボード矢印キー・WASD |
| 会話を進める | 画面をタップ / クリック |
| バトルコマンド | 画面のボタンをタップ |
| メニュー | 画面上部「メニュー」ボタン |

## ゲームの流れ

1. **タイトル** → なまえを入力
2. **オープニング** → クロスケと出会い、冒険開始
3. **マップ探索** → 各フィールドを歩くとモンスターが出現
4. **バトル** → ターン制。わざ・アイテム・ボール・にげる
5. **仲間化** → ボールで捕獲、またはイベント
6. **育成** → メニュー→そだてる（なでる・あそぶ・エサ）
7. **お店** → ほいくえんのおみせでアイテムを購入
8. **ラスボス** → じんじゃ→おくのほこら→やみのぬしを倒す
9. **エンディング** → クリア！

## マップ構成

```
ほいくえん（拠点・おみせ）
  ↕
こうえん（序盤フィールド）
  ↕
もり（中盤フィールド）
 ↙ ↘
じんじゃ  じゅうたくがい
  ↓
おくのほこら（ラスボス）
```

## MVPの範囲

- ✅ タイトル・なまえ入力・オープニング
- ✅ 5フィールドの探索（ランダムエンカウント方式）
- ✅ ターン制バトル
- ✅ モンスター8種類 + ラスボス1体
- ✅ レベルアップ・技習得
- ✅ 育成（なでる・あそぶ・エサ）
- ✅ お店・コイン
- ✅ ミニゲーム（おちばあつめ）
- ✅ localStorage セーブ/ロード
- ✅ 仮想十字キー（スマホ対応）
- ✅ エンディング

## 含まないもの（将来のVer.2候補）

オンライン対戦 / ガチャ / 進化システム / 属性相性 / モンスター交換 / ボイス

## 技術スタック

- TypeScript + Phaser 3
- Vite
- localStorage（サーバー不要）
- グラフィック: プレースホルダー（色付き矩形）、本番素材は `src/assets/assetKeys.ts` のキーで差し替え可
